# CV Portal — ارشیا

پرتال شخصی رزومه و مهارت‌های ارشیا — مهندس نرم‌افزار Senior و معمار راهکار

## 🌐 دسترسی

- **GitHub Pages:** https://arshiay.github.io/cvportal
- **Repository:** https://github.com/arshiay/cvportal

## 🛠 تکنولوژی‌ها

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Font Awesome 6
- Vazirmatn Font

## ✨ ویژگی‌ها

- ✅ تم تاریک/روشن (Dark/Light Mode)
- ✅ واکنش‌گرا (Responsive)
- ✅ انیمیشن‌های اسکرول
- ✅ ناوبری روان
- ✅ آمار شمارنده
- ✅ نوار مهارت متحرک

## 📁 ساختار

```
cvportal/
├── index.html    # صفحه اصلی
├── style.css     # استایل‌ها
├── script.js     # اسکریپت‌ها
└── README.md     # این فایل
```

## 🚀 دیپلوی (GitHub Pages)

برای انتشار روی GitHub Pages:

```
git push origin main
```

سپس در GitHub:
1. برو به Settings > Pages
2. منبع رو روی `main` و روت `/` بذار
3. ذخیره کن
