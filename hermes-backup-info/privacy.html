Privacy policy

Application: hermesBackup311
Effective date: 2026-10-16
Operator: Arshia YousefiAdib

This policy explains how the operator uses data in the personal hermesBackup311 backup utility. The app is for the operator’s private server. It is not offered as a public sign-in or storage service.

1. Data the app accesses

With the operator’s Google OAuth permission, the app can access backup file contents and Drive metadata. This can include file and folder names, IDs, sizes, and modification times. The app also uses OAuth tokens to keep authorized access. Backup archives can contain server files, databases, settings, and other data selected by the operator.

The requested Drive permission can grant broad access to the authorized account. The configured backup workflow limits its operations to the operator’s backup locations. This website does not receive Google passwords or OAuth tokens.

2. How data is used

The app uses this access to list backup locations, upload archives, download copies, check hashes, and recover backups. It keeps transfer and recovery records. Google API data is not sold or used for advertising, profiling, or AI model training by this backup utility.

3. Storage and sharing

Selected archives are stored in the operator’s Google Drive and Filen accounts. Separate configured backup workflows can also send selected archives to GitHub or Telegram. These services handle the copies sent to them under their own terms and privacy policies. The operator does not publish backup contents on this website.

4. Security

The app uses encrypted network connections for cloud transfers. Its configured Google Drive backup destination uses rclone crypt encryption. Access credentials are stored on the operator’s private server with restricted file permissions. SHA-256 checks are used to compare backup copies. No system can guarantee complete protection against every risk.

5. Retention and deletion

Cloud archives remain until the operator removes them or changes the backup policy. Local temporary files are needed to build and check archives. A completed local archive is removed only after copies and recovery records are checked on both cloud providers. A failed or incomplete transfer keeps its local source for retry.

Revoking access stops future authorized Drive operations. It does not remove archives already stored in Drive, Filen, GitHub, or Telegram. The operator must remove those copies from each service.

6. Access controls

The operator can stop the backup service and remove its stored credentials. Google access can also be revoked from Google Account connections. Requests about access or removal can be sent to the operator through the GitHub profile.

7. This public website

This is a static information site. It has no app analytics, sign-in form, upload form, or app-set cookies. GitHub Pages hosts the site and can process technical request data, such as IP addresses, under the GitHub Privacy Statement.

8. Google API data policy

The app’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Contact and changes

The operator is Arshia YousefiAdib. Use the operator’s GitHub profile for contact. Changes to this policy will be posted on this page with a new effective date.
