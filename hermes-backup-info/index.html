Private backup utility

hermesBackup311

A personal tool for storing and restoring the operator’s server backups.

Arshia YousefiAdib operates this tool for a private Hermes Agent installation. It is not a public storage service. Only the operator’s authorized Google account is used.

What the tool does

  • Uploads selected backup archives to Google Drive and Filen.
  • Downloads each copy and checks its SHA-256 hash.
  • Removes a completed local archive only after both cloud copies and their recovery records pass the checks.
  • Keeps a local pending copy if a transfer or a check fails.

Why Google Drive access is needed

The tool uses Google OAuth to access the operator’s Drive. It lists backup folders and files, uploads archives, and downloads them for checks or recovery. Configured backup paths limit its work. The OAuth permission can grant broader Drive access than those paths.

This website is an information page. It does not ask you to sign in, connect Google Drive, or upload a file. Google authorization takes place through Google, not through this page.

Read the privacy policy for details about data access, storage, sharing, and removal.
